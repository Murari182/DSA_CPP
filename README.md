## Notes: Common Mistakes to Avoid

- Off-by-one errors in loops (`i < n` vs `i <= n`).
- Forgetting base cases in recursion.
- Confusing 0-based and 1-based indexing.
- Not checking empty container conditions before `top()`, `front()`, or `pop()`.
- Ignoring integer overflow for large values.
- Forgetting to analyze both **time** and **space** complexity.
